# 06 · 分阶段实施清单 · 验收标准 · 风险

工作量按 1 名熟练前端的**有效工时**估算，合计约 **5–6 个工作日**（不含 P6 可选增强）。每个阶段结束时站点都必须处于"可部署、可演示"状态。

---

## 6.1 阶段总览

| 阶段 | 主题 | 估时 | 出口标志 |
|---|---|---|---|
| P0 | 骨架与底图 | 0.5 d | 手机/桌面都能打开、能拖地图、首屏 < 3 s |
| P1 | 检索闭环 | 1 d | 拖到某地 → 列出该地最新 32 景 |
| P2 | 出图与降级 | 1 d | 点任一景 → 看到 10 m 影像，失败也能降级 |

| P5 | 缓存 / 弱网 / 观测 | 0.5 d | 二次访问 < 1 s 出图 |
| P6 | 可选增强 | 按需 | 云掩膜 / 假彩色 / 官方源 / 自建渲染 |

## 6.2 逐阶段清单

### P0 · 骨架与底图（0.5 d）

**交付物**：`index.html` / `vite.config.ts` / `tsconfig.json` / `src/main.ts` / `src/config.ts` / `styles/*` / `ui/map/mapView.ts` / `services/basemap/sources.ts`

- [ ] Vite + TS strict 工程可 `npm run dev` / `npm run build`
- [ ] Leaflet 初始化（3857，z 3–18，默认中心北京 z11）
- [ ] EOX `s2cloudless-2025_3857` 底图 + **完整 attribution 字符串**
- [ ] 三套断点布局骨架（空面板即可）
- [ ] 骨架屏 + `preconnect` 4 个主机
- [ ] 地图版权角标 + 关于弹层（数据来源声明）

**验收标准**
1. Lighthouse **mobile**（4G 节流）：LCP < 2.5 s，TBT < 200 ms，CLS < 0.1。
2. `dist/` 体积：JS ≤ 90 KB gz、CSS ≤ 12 KB gz。
3. iPhone SE / 小米中端机 + Chrome 桌面：地图可拖动、双指/滚轮缩放，无控制台报错。
4. 网络面板确认：首屏除瓦片外请求 ≤ 8 个，且**无任何 API Key 参数**。
5. 断网刷新：页面不白屏，显示"离线/网络不可用"提示。

### P1 · 检索闭环（1 d）

**交付物**：`domain/{bbox,dates,scene,types}.ts` / `services/stac/{earthSearch,normalize}.ts` / `services/http.ts` / `ui/map/footprintLayer.ts` / `ui/panels/sceneStrip.ts`

- [ ] `bbox.ts`：3857↔4326、取整、面积上限、跨线裁剪（**纯函数，附单测**）
- [ ] `earthSearch.ts`：查询构造 / 分页 / 错误分类 / 超时 8 s / `AbortSignal`
- [ ] `normalize.ts`：STAC Item → `Scene`（含 `thickCloud` 计算）
- [ ] 客户端排序（**不要用 `sortby`**，实测该参数报错）
- [ ] 足迹图层（选中态 / hover 态）
- [ ] 场景条（缩略图 + 日期 + 云量 + `2A` 徽章）

**验收标准**
1. 北京 z11 打开 → 90 天内结果 ≤ 5 s 出现（冷启），命中数 > 0。
2. 连续拖地图 10 次：只有**最后一次**结果落地，无错序、无重复渲染（用 `requestToken` 证明）。
3. 云量设 10% 时结果数 ≤ 云量 50% 时结果数（单调性）。
4. 断网 / 改错 STAC_BASE → 显示错误态与重试，底图不受影响。
5. `domain/*` 单测覆盖：bbox 取整、面积上限、日期区间、`thickCloud` 计算 → 全绿。

### P2 · 出图与降级（1 d）

**交付物**：`services/render/{titiler,fallback}.ts` / `app/renderFlow.ts` / `ui/map/imageOverlay.ts` / `domain/zoomTier.ts`

- [ ] **第一件事：验证 `/cog/bbox/{bbox}.jpg` 后缀可用**（实测同端点 PNG 为 1.94 MB，不可接受）
- [ ] T1–T4 分级策略 + `dst_crs=EPSG:3857`
- [ ] 淡入 200 ms、加载骨架、失败占位
- [ ] 降级链 D0–D3 全部打通
- [ ] 竞态防护：快速拖动/连续点选不出现"张冠李戴"

**验收标准**
1. 点选任一景，z13 下 **≤ 4 s** 出图；像素与原站对照无明显偏移（叠加足迹边界，误差 < 30 m）。
2. 把 `VITE_TITILER_BASE` 改成不可达地址 → 3 s 内自动降级到缩略图并提示"低清预览"，**不出现破图**。
3. 连续点 5 个不同场景，最终显示的场景 id 与最后一次点击一致。
4. 单次出图体积 ≤ 500 KB（网络面板核对）；`z ≥ 17` 出现"已达原始分辨率上限"提示。
5. 断点续传/取消：拖动中不累积未取消请求（DevTools 中最多 1 个 pending 渲染请求）。

### P3 · 时间轴 / 云量 / 地名搜索 / 分享（1 d）

**交付物**：`ui/controls/*` / `ui/panels/sceneDetail.ts` / `app/urlState.ts` / `services/geocode/nominatim.ts`

- [ ] 时间区间预设（7/30/90/365 天）+ 可用成像日期滑杆
- [ ] 云量滑杆（0–100，默认 20，"整景平均"说明文案）
- [ ] "仅 Sentinel-2A" 开关（**默认关**，见风险 R3）
- [ ] Nominatim 地名搜索（500 ms 防抖、≥2 字符、结果缓存、遵守 1 req/s）
- [ ] 矩形框选 → 以框为 bbox 检索
- [ ] 详情抽屉：元数据 + STAC JSON + COG 直链（标体积）+ Copernicus Browser 深链
- [ ] URL hash 全量同步（分享/刷新/前进后退）

**验收标准**
1. 分享链接在**另一台设备**打开：视图、时间范围、云量、选中场景完全一致。
2. 搜"上海外滩"能定位并自动检索；连续输入不触发 > 1 req/s。
3. 框选 0.1°×0.1° 区域 → 只返回覆盖该框的景，且选中景足迹与框相交（几何校验）。
4. 云量/时间任一改动 → 结果与"最新/最佳"徽章同步更新，且不重复请求未变维度。
5. 详情里每个下载入口都能打开有效响应（COG 直链返回 206）。

### P4 · 移动端打磨（0.5–1 d）

**交付物**：`ui/panels/bottomSheet.ts` / 布局与样式定稿

- [ ] 抽屉三档（peek 88 / half 52 vh / full 92 vh）+ 跟手吸附
- [ ] 触控目标 ≥ 44 px、`safe-area-inset` 全适配
- [ ] 搜索聚焦时抽屉上推、键盘收起回位
- [ ] 横屏侧栏态
- [ ] `saveData` / 2g-3g 自动降级画质

**验收标准**
1. iPhone SE（375×667）与 Pixel 7 真机/模拟器：**单手**完成"看最新 → 换一天 → 看详情 → 打开官网"全流程，无需换手。
2. 地图可见高度 ≥ 60 vh（peek 态实测）。
3. 抽屉拖动无卡顿（DevTools Performance 60 fps，无长任务 > 50 ms）。
4. 刘海屏/圆角屏内容不被裁切；横屏不出现纵向滚动条。
5. 所有交互元素可达 44 px（用 DevTools 逐个量，或写一条自动检测脚本）。

### P5 · 缓存 / 弱网 / 观测（0.5 d）

**交付物**：`services/cache/*` / 可选 `sw.ts`

- [ ] L1 内存 LRU（含 `revokeObjectURL` 防内存泄漏）
- [ ] L2 `localStorage` 查询快照（8 条 / 10 min）
- [ ] L3 IndexedDB 图片缓存（80 MB 上限）
- [ ] P5 可选 Service Worker：`index.html` network-first，图片 cache-first
- [ ] 本地错误计数（`localStorage`），"关于"页可查看/清空（不接第三方埋点，保护隐私）

**验收标准**
1. 二次访问（同场景）出图 < 1 s，网络面板显示 from cache。
2. 连续切换 50 个场景后，`performance.memory` 无明显增长（`revokeObjectURL` 生效）。
3. 飞行模式 + 已缓存 → 仍能看到上次的影像与列表。
4. 清空缓存后行为与首次访问一致（无隐性状态依赖）。

### P6 · 可选增强（按需，各 0.5–1 d）

| 项 | 价值 | 成本 |
|---|---|---|
| 客户端 `geotiff.js` 渲染（读 S3 COG，彻底摆脱公共 titiler） | 消除最大的外部依赖 | +30 KB，2 d（含 uint16 拉伸 LUT） |
| CDSE Sentinel Hub 免费账号 WMS（真云掩膜 / 假彩色 / 按景 TIME） | 质量跃升 | 需账号；凭据暴露需评估（见 R7） |
| 自建 titiler（Cloudflare Worker / Deno） | 可控 SLA + 边缘缓存 | 半天 + 运维 |
| NASA GIBS 每日真彩叠加层 | "今天" 也能看 | 0.5 d |
| 变化检测（两期对比 / 卷帘） | 强需求 | 2–3 d（需固定两景 + 合成） |
| SCL 云影掩膜叠加 | 直观判断可用性 | 1 d |

## 6.3 风险登记表

| ID | 风险 | 概率 | 影响 | 缓解措施 | 预警信号 |
|---|---|---|---|---|---|
| **R1** | 公共 `titiler.xyz` 无 SLA：限流、变慢或下线 | **高** | 高（核心看图功能） | 三级降级链（D1–D3）；`VITE_TITILER_BASE` 一行切换；P6 客户端渲染兜底 | 连续 3 次 > 8 s 或 429 → 自动切 D2 并记录 |
| **R2** | 中国大陆网络到 AWS us-west-2 / 奥地利 EOX 延迟高 | **高** | 中（首屏与出图变慢） | `preconnect`；单请求渲染（非瓦片）；本地缓存；必要时换 OSM 底图或边缘反代 | 首屏 > 3 s 或单请求 > 5 s 的占比 > 30 % |
| **R3** | 只筛 Sentinel-2A 会显著降低时效（单星 ~10 天重访） | 中 | 中（用户抱怨"没有最新"） | 默认全星座（2A/2B/2C）+ 场景打 `2A` 徽章；"仅 2A"作为显式开关 | 勾选 2A 后结果数为 0 时立即提示 |
| **R4** | 整景云量 ≠ 目标区无云，用户误判 | **高** | 中（信任损失） | 云量旁强制说明；用 `thickCloud` 排序；空结果给"放宽云量/扩大时间"引导；P6 上 SCL | 用户反馈"图上是云" |
| **R5** | 大 bbox（省/国）返回上千景、出图像素爆炸 | 中 | 中（卡顿/流量） | bbox 面积上限 1.5°；`max_size` ≤ 2048；强制 JPEG；结果只取首页 100 + `+N` 提示 | 单次响应 > 2 MB |
| **R6** | **EOX 底图授权**：免费瓦片为非商业许可，商业使用需付费 | 中 | **高（法务）** | UI 保留原始 attribution；商业化前切 OSM 或 CDSE 免费账号 WMS；上线前法务确认 | 站点开始承接商业用途 |
| **R7** | 若接入 CDSE 免费账号，`client_secret` 暴露在浏览器 | 中 | 高（配额被盗用/封号） | 默认不接入；若必须，用"仅内存、不落盘、提示风险"或走边缘函数代理；**绝不写进构建产物** | 出现异常配额消耗 |
| **R8** | 旧集合 `pre-c1-l2a` 为 JP2，个别日期 c1 缺数据 | 低 | 低 | 明确提示"该日无可用影像"；不接入 JP2 路径 | 某区域某日命中 0 |
| **R9** | iOS `100vh` 地址栏导致布局跳动 | 中 | 低 | 用 `100dvh` + `vh` 回退；抽屉 `max-height` 用 `dvh` | 真机首次滚动后底部被裁 |
| **R10** | 单景 TCI 357 MB 直链被移动端误点 | 中 | 中（流量投诉） | 直链按钮标注体积 + 二次确认；默认给 45 KB 缩略图下载 | 用户反馈"点了下载几个 G" |
