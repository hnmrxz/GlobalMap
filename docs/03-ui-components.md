# 03 · 页面与组件拆分

单页应用（SPA），无路由框架；三个断点三套布局，共用同一份组件与状态。

## 3.3 组件契约

| 组件 | 输入（props） | 输出（事件） | 职责边界 / 不做的事 |
|---|---|---|---|
| `MapView` | `view{z,x,y}`、`basemap`、`scenes`、`selectedId`、`imageSrc` | `onViewChange(bounds,zoom)`、`onScenePick(id)`、`onBoxDrawn(bbox)` | 只管地图与图层；**不发请求** |
| `SearchBox` | `value` | `onQuery(text)`、`onPick(place)` | 防抖 500 ms、缓存、≥2 字符才查；不做地理编码解析细节 |
| `DateRail` | `range{from,to}`、`availableDates`、`selectedDate` | `onRange(preset)`、`onDate(id)` | 只产出日期区间；不做检索 |
| `CloudSlider` | `value(0–100)` | `onChange(v)`（change 才触发，input 只更新数字） | |
| `SceneList` | `scenes`、`selectedId`、`loading` | `onPick(id)`、`onLoadMore()` | 虚拟滚动不必做（limit 100 足够） |
| `SceneStrip` | 同上 | `onPick(id)` | 移动端隐藏（内容合入抽屉） |
| `SceneImageLayer` | `src`、`bounds`、`state(idle/loading/ok/error)` | `onError(kind)` | 负责淡入与占位；不决定用哪个 URL |
| `SceneDetail` | `scene` | `onClose`、`onDownload(kind)` | 展示元数据；下载只是打开链接（无后端） |
| `StatusBanner` | `kind`、`message`、`action?` | `onAction()` | 所有提示的唯一出口（避免 toast 满天飞） |

**没有 `App` 级 props 逐层传递**：`app/store.ts` 的 `subscribe` 让每个组件自取所需切片，组件内部只在 `mount()` 时注册一次。

## 3.4 主流程（必须以最少点击完成）

| 目标 | 路径 | 点击数 |
|---|---|---|
| 看"我家附近最新影像" | 打开页面（自动定位/上次位置）→ 自动检索 → 自动选中最新一景 → 出图 | **0** |
| 换个地方看 | 拖地图 → 400 ms 后自动重查 → 自动选中最新 | 0（拖动） |
| 看某天的影像 | 点时间轴上的点 / 场景条缩略图 | 1 |
| 只看 2A | 顶栏勾选"仅 2A" | 1 |
| 提高清晰度 | 放大到 z≥13（自动升级策略） | 0（缩放） |
| 框选指定区域 | 点 `▣` → 拖矩形 → 自动检索该框 | 2 |
| 拿原图/去官网 | 点缩略图 → 详情 → "下载 COG / 在 Copernicus Browser 打开" | 3 |

**自动选中策略**：`scenes[0]`（datetime 最新、云量 ≤ 阈值）；若最新一景云量高于阈值但用户未改阈值，仍选中但给 `StatusBanner` 提示"N 景中最佳：10-25（云量 2%）"，并高亮"最佳"徽章——避免"最新=全云"的挫败感。

## 3.5 三态设计

| 状态 | 触发 | 表现 |
|---|---|---|
| **空** | 检索结果 0 景 | 地图保留底图；面板显示"该区域近 90 天无云量 ≤20% 的影像"，附三个可点建议：放宽云量 / 扩大时间范围 / 缩小范围；**不要**显示空白列表 |
| **错** | STAC 失败 / titiler 失败 | `StatusBanner` + 重试按钮；区分文案：「检索服务无响应（点击重试）」/「影像渲染超时，已切换为低清预览」 |
| **慢** | 请求 > 3 s | 骨架屏 + 进度文案「正在渲染 10 m 影像…」；> 8 s 自动降级（D2） |
| **降级** | D2/D3 生效 | 影像区打角标「低清预览」，详情里说明原因并提供直链 |

## 3.6 文案与可达性

- 全部中文；时间显示 **北京时间 + UTC 双标**（`2026-11-02 11:16 (UTC 03:16)`），避免跨时区误读。
- 云量显示为 `0.4%`，悬停/长按提示"整景平均云量，不代表目标区域无云"。
- 键盘：`Tab` 可遍历所有控件；`Esc` 关抽屉；地图容器 `role="application"` + `aria-label="卫星影像地图"`。
- 对比度 ≥ 4.5:1；不用纯图标按钮而不给 `aria-label`。
- 角标 attribution 恒定可见（法规要求），移动端允许折成两行但不可隐藏。
